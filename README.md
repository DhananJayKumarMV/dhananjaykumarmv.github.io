# dhananjaykumarmv.github.io

Personal portfolio site — live at [dhananjaykumarmv.github.io](https://dhananjaykumarmv.github.io).

Single-page site with sections for an intro/hero, about, experience, education, skills, and projects, plus a separate anime showcase page.

## Stack

Vite · React · TypeScript · Tailwind CSS · shadcn/ui

## Development

```bash
git clone https://github.com/DhananJayKumarMV/dhananjaykumarmv.github.io.git
cd dhananjaykumarmv.github.io
npm install
npm run dev
```

Build for production with `npm run build`; output goes to `dist/`.

This project was originally scaffolded with [Lovable](https://lovable.dev) and is now maintained directly in this repo.
